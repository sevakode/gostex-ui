Every scene has a visible reference and localized title, description, reference source and honest image credit. `world` is independent of category: if a prepared image cannot decode, the native fallback retains its world. Hyrule and Tatooine have dedicated native fallbacks; they cannot turn into Tetris merely because of category priority. Catalog checks reject unsupported worlds and identical prepared images assigned to different worlds.

Each painting carries an `ArtDirection` profile with authored `ArtTreatment` choices: reveal style, pixel-grid dimensions and whether the finished painting retains that grid. Auto chooses among those treatments for that painting, using a session seed and scene index. Pixel scale belongs to the composition rather than a separate global large/small-pixel mode. For example, Gotham uses scene composition, ink and still treatments; the Tetris painting can assemble chunky blocks and keep its deliberate pixel grid. Scene landmarks continue to guide contours and light. A global cycle applying the same eight effects to unrelated paintings, documented during 0.16.0 development, is superseded.

The drawer exposes three programs: **Auto · varied scenes**, **Calm scenes** and **Still paintings**. Calm uses only eligible SCENE, INK, TILES, FOCUS or STILL treatments from the current painting, falling back to SCENE if its profile contains only motion. Still shows complete paintings without an animated reveal. Previously saved concrete styles remain readable; changing the program cycles through the three current choices. The retired snake-as-reveal renderer is removed: a legacy SNAKES preference falls back to SCENE for a painting instead of turning Snake back into its reveal effect.

Turning interludes off retains all painting slots; Calm and Still omit the independent act. ## Remote

Remote auto-start is a saved preference. The boot receiver invokes only `$HOME/start-codex.sh` through Termux's permission-checked RUN_COMMAND API and a foreground-service request; it accepts no command from external intents. Termux requires its explicit RUN_COMMAND grant and `allow-external-apps=true`. The supervisor uses a single-instance lock, checks local ADB and reconnects the existing paired Codex server. No ChatGPT credentials are bundled.

A real reboot and connected/paired/local-ADB state were previously verified; the same status was confirmed after 0.13.1. Development and this chat remain on the PC. No session migration is required for the launcher or native weekly artwork.
